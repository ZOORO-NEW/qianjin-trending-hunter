## 三、搜索执行策略

### 3.1 搜索关键词模板

**国内搜索模板**：
```
"[行业名] 热点 [本周/今天/最新]"
"[行业名] 热搜 [平台名]"
"[行业名] 爆款 [本周]"
"[具体事件] 网友热议"
"[具体事件] 评论 转发"
```

**国际搜索模板**：
```
"[industry] trending [this week/today]"
"[industry] viral [platform]"
"[specific event] discussion"
"[industry] breaking news"
```

### 3.2 多轮搜索策略

```
第1轮（广撒网）：
  搜索 "[行业名] 热点 本周" → 获取行业整体热点列表

第2轮（深挖掘）：
  搜索 "[具体热点事件] 网友评论" → 获取评论数和转发量数据

第3轮（国际化）：
  搜索 "[industry] trending this week" → 获取国际版热点

第4轮（差异化）：
  搜索 "[具体热点事件] 不同观点/争议" → 获取差异化角度
```

### 3.3 热度评估标准

| 指标 | 权重 | 数据来源 |
|------|------|---------|
| 平台热搜排名 | 30% | 各平台热搜榜单 |
| 讨论量/评论数 | 25% | 原帖评论数 |
| 转发/分享量 | 20% | 原帖转发数 |
| 多平台覆盖度 | 15% | 同一话题在多个平台出现 |
| 持续时间 | 10% | 话题已持续天数 |

**热度评分公式**：
```
热度分数 = (热搜排名得分 × 30%) + (讨论量得分 × 25%) + (转发量得分 × 20%) + (多平台覆盖得分 × 15%) + (持续时间得分 × 10%)
```

### 3.4 时间窗口建议

| 报告类型 | 时间范围 | 建议生成时间 | 适用场景 |
|---------|---------|------------|---------|
| 日报 | 过去24小时 | 每日上午9:00 | 追突发热点 |
| 周报 | 过去7天 | 每周一上午 | 周度选题规划 |
| 月报 | 过去30天 | 每月1日 | 月度内容规划 |
| 专题报 | 不限 | 按需 | 深度行业分析 |

## 四、平台数据互补策略

不同平台的数据互补关系：

```
微博热搜 → 实时性最强，适合发现突发热点
知乎热榜 → 深度讨论，适合判断话题深度价值
抖音热点 → 传播力最强，适合判断大众化程度
B站热门 → 年轻人关注点，适合判断Z世代趋势
小红书 → 消费/生活趋势，适合判断女性受众兴趣
36氪/虎嗅 → 行业专业视角，适合判断产业价值
Google Trends → 全球趋势，适合国际版选题
Twitter/X → 国际实时讨论，适合发现全球热点
Hacker News → 科技前沿，适合科技/AI行业
```

**最佳实践**：每个行业至少搜索3个平台，交叉验证热度排名。
